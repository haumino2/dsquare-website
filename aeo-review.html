AEO / GEO Review

Full-site audit of the DSQUARE prototype against Figma, Growth Partner positioning, brand quality, IA, and AEO/GEO. This page is the review surface — public pages stay brand-first.

Review verdict

The prototype is an evolution of the current Figma — campaign-led, dark, sharp, opinionated — with structural AEO clarity. Latest audit removed the SEO-looking hero box, differentiated the four capabilities, and cleaned taxonomy/linking without redesigning the brand.

Latest audit findings (fixed)

  • Hero positioning box felt like an AEO annotation — replaced with native eyebrow + supporting paragraph (scrim + type contrast only).
  • “Four capabilities. One partner.” was generic — rewritten to “What we own when growth is the brief.”
  • Commerce leaned on vague “data” language — refocused on strategy, storefront, purchase journey, ops, and platform integrations; removed Mitsubishi as Commerce proof.
  • Digital Solutions was abstract — made concrete (CDI / marketing-to-sales platforms, architecture, operable builds); removed unevidenced Suzuki link.
  • Capability blur — each pillar now has distinct problems / what we deliver / work / insights; labels use full capability names sitewide.
  • Minor IA — “All works” → “All work”; Insights teaser no longer says “Subscribe” without a form.

1. Kept from Figma

  • Campaign-led Fronx hero as full-bleed first viewport.
  • Dark identity, blue/amber accents, editorial work cards, large DSQUARE footer.
  • Challenge / Solution / Impact case structure.
  • Voice: work runs the show, fuse sharp ideas, commerce “hate the hassle,” client quote.

2. Modified

  • Hero: campaign H1 + Growth Partner as native supporting copy (not a boxed callout).
  • Capability gateway H2 and card blurbs differentiated by ownership and outcome.
  • Services pillars rewritten for clear problem / deliverable / proof boundaries.
  • UI: less SaaS pill/glow; editorial capability rows.
  • Work tags and related links tightened to evidenced ownership.

3. Added for AEO / GEO

  • Entity: DSQUARE = Growth Partner Agency in Vietnam + four capabilities in visible text.
  • Consistent taxonomy across Home, Services, Work, Insights, Contact, Footer.
  • DSQUARE’s Role on every case; publish-only metrics.
  • Insights module with capability categories and expertise notes.
  • Service ↔ Work ↔ Insights contextual links.

4. Removed / avoided

  • Hero amber “annotation” panel; meta page-purpose chips; strategy-doc labels on public pages.
  • Generic SaaS H1; invented stats; placeholder/Lorem/Rayo leftovers.
  • Vague Commerce “data” framing; over-claimed Work↔Service links (Suzuki as Digital; Mitsubishi as Commerce).
  • Self-referential AEO blog post.
