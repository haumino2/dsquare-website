# DSQUARE website prototype (AEO/GEO)

Clickable HTML prototype based on the current Figma file (`Company website (Copy).fig`), with AEO/GEO structure improvements.

## Open locally

```bash
python -m http.server 8765
```

Then visit: http://127.0.0.1:8765/index.html

## Pages

| Page | File |
|------|------|
| Homepage | `index.html` |
| Services | `services.html` |
| Work index | `work.html` |
| Case studies | `work-suzuki-fronx.html`, `work-ariston.html`, `work-mitsubishi.html`, `work-gojek.html` |
| Insights index | `insights.html` |
| Insight articles | `insight-*.html` |
| About | `about.html` |
| Contact | `contact.html` |
| AEO Review | `aeo-review.html` |

Floating **AEO Review** button appears on every page.
